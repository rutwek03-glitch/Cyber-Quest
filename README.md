# CYBER//QUEST Original Full-Stack
Student accounts + PostgreSQL persistence + animated cybersecurity examples.

## Demo
Email: student@cyberquest.demo

## Local
Create a PostgreSQL database, copy `.env.example` to `.env`, set DATABASE_URL and SESSION_SECRET, then `npm install` and `npm start`.

## Render
Use a Node Web Service. Build: `npm install`; Start: `npm start`. Add DATABASE_URL and SESSION_SECRET. For real classroom deployment, attach a managed PostgreSQL database. Do not commit `.env`.

## Features
Login/register, hashed passwords, sessions, persistent XP/progress, leaderboard, 12 learning zones, daily mission/fact/quiz, animated phishing/network/encryption/SOC simulations.

Educational use only; real security testing requires authorization.
